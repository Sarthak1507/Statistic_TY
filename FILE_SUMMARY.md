# File Summary

## Statistical Analysis Project

This document describes the purpose of each major file and folder in the `Statistic_TY` project.

---

## 1. Root Files

### `README.md`

The main documentation file of the repository.

It provides:

- Project introduction
- Project objectives
- Technologies used
- Project structure
- Installation instructions
- Notebook execution order
- Dataset information
- Author information

---

### `requirements.txt`

Contains the Python libraries required to run the project.

Main dependencies include:

```text
pandas
numpy
scipy
matplotlib
seaborn
openpyxl
jupyter
ipykernel
```

Install them using:

```bash
pip install -r requirements.txt
```

---

### `.gitignore`

Specifies files and folders that should not be committed to Git.

Examples include:

```text
__pycache__/
.ipynb_checkpoints/
.venv/
.vscode/
outputs/
```

---

## 2. Data Folder

### `data/`

Stores the input dataset used by the project.

### `data/Statics_data.xlsx`

The main Excel dataset for the statistical analysis.

It is loaded by:

```text
01_data_loading.ipynb
```

The dataset should remain in the `data` folder so that all notebooks can use a consistent project structure.

---

## 3. Notebook Folder

### `notebook/`

Contains the complete statistical analysis workflow.

---

### `01_data_loading.ipynb`

Responsible for loading and preparing the dataset.

Main operations:

- Import Excel data
- Inspect rows and columns
- Check data types
- Check missing values
- Process date information
- Prepare cleaned data

---

### `02_descriptive_stats.ipynb`

Performs descriptive statistical analysis.

Main operations:

- Mean
- Median
- Standard deviation
- Minimum
- Maximum
- Percentiles
- Summary statistics

---

### `03_data_visualization.ipynb`

Creates graphical representations of the data.

Possible visualizations include:

- Line plots
- Histograms
- Box plots
- Distribution plots
- Comparison plots

---

### `04_trend_analysis.ipynb`

Studies trends and changes in the dataset.

Main operations may include:

- Time-based analysis
- Returns calculation
- Moving averages
- Trend analysis
- Regression-based analysis

---

### `05_normality_tests.ipynb`

Performs statistical tests for normality.

The notebook helps determine whether selected variables approximately follow a normal distribution.

---

### `06_correlation_analysis.ipynb`

Studies relationships between numerical variables.

Main operations include:

- Correlation calculation
- Correlation matrix
- Heatmap visualization
- Interpretation of relationships

---

### `07_hypothesis_testing.ipynb`

Performs hypothesis testing using appropriate statistical methods.

The notebook may include:

- One-sample t-test
- Paired t-test
- Two-sample t-test
- Mann-Whitney U test
- Levene's test
- Effect-size calculations

---

### `08_statistical_summary.ipynb`

Provides a final summary of the statistical analysis.

It combines important outputs from earlier notebooks and creates a consolidated statistical summary.

---

## 4. Output Folder

### `outputs/`

Stores files generated during analysis.

Examples:

```text
cleaned_data.csv
descriptive_statistics.csv
hypothesis_tests.csv
statistical_summary_report.txt
```

### `outputs/plots/`

Stores graphs and visualizations generated by the analysis notebooks.

This keeps generated images separate from the source notebooks and dataset.

## 9. Important Path Configuration

Because the notebooks are inside the `notebook` folder, the dataset should be accessed using:

```python
file_path = '../data/Statics_data.xlsx'
```

Similarly, if the project wants generated files in the root `outputs` folder, notebooks should use paths such as:

```python
'../outputs/cleaned_data.csv'
```

and:

```python
'../outputs/plots/'
```
