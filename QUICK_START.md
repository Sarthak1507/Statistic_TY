# Quick Start Guide

## Statistical Analysis Project

This guide explains how to set up and run the Statistical Analysis Project using Python and Jupyter Notebook.

---

## 1. Project Requirements

Make sure the following are installed:

- Python 3.10 or later
- Jupyter Notebook or JupyterLab
- VS Code (recommended)
- Python extension for VS Code

---

## 2. Project Structure

```text
Statistic_TY/
├── notebook/
│   ├── 01_data_loading.ipynb
│   ├── 02_descriptive_stats.ipynb
│   ├── 03_data_visualization.ipynb
│   ├── 04_trend_analysis.ipynb
│   ├── 05_normality_tests.ipynb
│   ├── 06_correlation_analysis.ipynb
│   ├── 07_hypothesis_testing.ipynb
│   └── 08_statistical_summary.ipynb

│   └── Statics_data.xlsx
│
├── Report/
│   └── Project_Report.md
│
├── outputs/
│   └── plots/
│
├── README.md

├── JUPYTER_SETUP.md
├── PROJECT_INDEX.md
```

---

## 3. Install Required Libraries

Open the terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

The required libraries include:

- pandas
- numpy
- scipy
- matplotlib
- seaborn
- openpyxl
- jupyter
- ipykernel

---

## 4. Open the Project

Open the `Statistic_TY` folder in VS Code.

Then open:

```text
notebook/
```

---

## 5. Run the Notebooks in Order

Run the notebooks in the following sequence:

### Step 1
`01_data_loading.ipynb`

Loads and prepares the Excel dataset.

### Step 2
`02_descriptive_stats.ipynb`

Calculates descriptive statistics such as:

- Mean
- Median
- Standard deviation
- Minimum
- Maximum
- Percentiles

### Step 3
`03_data_visualization.ipynb`

Creates statistical graphs and visualizations.

### Step 4
`04_trend_analysis.ipynb`

Performs trend and time-series analysis.

### Step 5
`05_normality_tests.ipynb`

Performs normality testing on selected variables.

### Step 6
`06_correlation_analysis.ipynb`

Analyzes relationships between numerical variables.

### Step 7
`07_hypothesis_testing.ipynb`

Performs statistical hypothesis tests.

### Step 8
`08_statistical_summary.ipynb`

Combines the analysis results into a statistical summary.

---

## 6. Dataset Location

The project dataset should be stored at:

```text
data/Statics_data.xlsx
```

Because the notebooks are inside the `notebook` folder, use the relative path:

```python
file_path = '../data/Statics_data.xlsx'
```

---

## 7. Output Files

Generated files should be stored inside:

```text
outputs/
```

Plots should be stored inside:

```text
outputs/plots/
```

---

## 8. Recommended Execution Order

Always execute the notebooks in this order:

```text
01 → 02 → 03 → 04 → 05 → 06 → 07 → 08
```

Some notebooks use files generated by earlier notebooks, so running them in order helps avoid missing-file errors.

---

## 9. Troubleshooting

### ModuleNotFoundError

Run:

```bash
pip install -r requirements.txt
```

### Excel file not found

Check that the file exists here:

```text
data/Statics_data.xlsx
```

and that the notebook uses:

```python
file_path = '../data/Statics_data.xlsx'
```

### Kernel not available in VS Code

Install the Python kernel:

```bash
python -m pip install ipykernel
```

Then select the correct Python interpreter/kernel in VS Code.
